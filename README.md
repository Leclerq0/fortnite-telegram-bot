# 🛒 Basic Fortnite Daily Shop Telegram Bot

**Developed by:** Mustafa Cihat
**Tech Stack:** Python, Telegram Bot API, REST APIs

## 🚀 Overview
A Python-based Telegram bot that automatically fetches the daily Fortnite Item Shop data, localizes it to Turkish, structures it by categories (Skins, Pickaxes, emotes, etc.), and sends a clean and basic report to a personal Telegram account.

## ✨ Key Features
* **Real-time Data Fetching:** Connected to unofficial Fortnite APIs via the `requests` library.
* **Localization:** Shop items are displayed in **Turkish** using API query parameters.
* **Data Structuring:** Raw JSON data is categorized using Python dictionaries and lists for a structured and readable output.
* **Telegram Integration:** Uses Telegram Bot API to send formatted HTML messages.
